title: QA Interview Requirements
last_updated: 2024-03-10
---
Candidates for the QA Engineer position must have at least 2 years of experience with test automation frameworks such as Selenium or Cypress. Strong understanding of the software testing lifecycle (STLC) is required. Candidates should be comfortable writing test plans and test cases from user stories. Experience with CI/CD pipelines (Jenkins, GitHub Actions, or Azure Pipelines) is a plus. Basic SQL knowledge for database validation is expected.
